Art direction

Two rules doing most of the work

Serif is human, monospace is machine. The developer's intent is set in Instrument Serif on cream paper. Everything Claude Code does is JetBrains Mono on ink. The film crosses that line exactly twice: once when the prompt is handed over, once when the result comes back. Nothing else has to explain the handoff.

The HUD carries the structure. A persistent mark, chapter label, and progress line mean no shot has to introduce itself. The type colour crossfades between ink and cream at the two background changes rather than cutting, so the furniture never flickers.

Reproduce

From a clean clone

npm install then npm run dev for the Remotion Studio, or npm run build to render the MP4 to out/claude-code-film-Cursor.mp4. The shot durations and transition overlaps live in one file, src/timeline.ts, and the total is asserted to land on 1200 frames.

The scenario is illustrative. The checkout API, the request chart, and the latency and 429 figures are written for the film. They are not measurements of Claude Code or of any live service.
